# Fewer Photos

The official companion website for Fewer Photos, an iPhone app for reviewing a camera roll month by month.

Fewer Photos helps people keep meaningful photographs, safely queue unwanted images and collect stamps while tidying their library.

## Development

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
